# Clear Battle Command Targets

## **Clear Battle Command Targets**[¶](#clear-battle-command-targets "Permanent link")

Removes targeting indicators from all battlers in the current battle.

## **Examples**[¶](#examples "Permanent link")

#### **Clear All Targeting Indicators**[¶](#clear-all-targeting-indicators "Permanent link")

This removes all targeting indicators from every battler in the current battle.
