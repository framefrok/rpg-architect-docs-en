# Pause Battle

## **Pause Battle**[¶](#pause-battle "Permanent link")

Pauses or resumes a running battle; with no mode specified, the entire battle is paused.

## **Properties**[¶](#properties "Permanent link")

#### **System**[¶](#system "Permanent link")

Name

Explanation

Type

Mode

Whether to fully freeze the battle, freeze only its actions, or resume it.
