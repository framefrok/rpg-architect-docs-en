# Set Minimap Level

## **Set Minimap Level**[¶](#set-minimap-level "Permanent link")

Sets which level of the minimap is displayed, or returns it to automatic level selection based on the player's elevation.

## **Properties**[¶](#properties "Permanent link")

#### **System**[¶](#system "Permanent link")

Name

Explanation

Type

Automatic

Whether to return the minimap to automatic level selection based on the player's elevation.

Toggle

Level

The index of the minimap level to display.

[Variable or Value](../../../05-reference/variable-or-value/)

Minimap

The minimap user interface to target. Leave as Default to use the first minimap user interface, or provide a unique ID through a variable.

[Variable or Value](../../../05-reference/variable-or-value/)
