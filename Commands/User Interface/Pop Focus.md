# Pop Focus

## **Pop Focus**[¶](#pop-focus "Permanent link")

Removes the current focus from a user interface element, restoring focus to the previously focused element.

## **Examples**[¶](#examples "Permanent link")

#### **Remove the Current Focus from the User Interface**[¶](#remove-the-current-focus-from-the-user-interface "Permanent link")

This removes the current focus, restoring focus to the previously focused element in the user interface.
