# Toggle Minimap

## **Toggle Minimap**[¶](#toggle-minimap "Permanent link")

Opens the minimap user interface when it is closed, or closes it when it is open. Leave the minimap as Default to use the first minimap user interface.

## **Properties**[¶](#properties "Permanent link")

#### **System**[¶](#system "Permanent link")

Name

Explanation

Type

Minimap

The minimap user interface to target. Leave as Default to use the first minimap user interface, or provide a unique ID through a variable.
