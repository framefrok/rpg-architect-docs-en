# Close Minimap

## **Close Minimap**[¶](#close-minimap "Permanent link")

Closes an open minimap user interface. Leave the minimap as Default to close the open minimap.

## **Properties**[¶](#properties "Permanent link")

#### **System**[¶](#system "Permanent link")

Name

Explanation

Type

Minimap

The minimap user interface to target. Leave as Default to use the first minimap user interface, or provide a unique ID through a variable.
