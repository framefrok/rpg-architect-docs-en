# Clear Graphics Post-Processors

## **Clear Graphics Post-Processors**[¶](#clear-graphics-post-processors "Permanent link")

Removes all runtime post-processing effects from the current scene. Optionally limit it to a single layer (scene, user interface, or composite). Authored effects configured in the database are not affected.
