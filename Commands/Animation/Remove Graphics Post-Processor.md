# Remove Graphics Post-Processor

## **Remove Graphics Post-Processor**[¶](#remove-graphics-post-processor "Permanent link")

Removes a runtime post-processing effect from the current scene by its unique ID, as returned by Add Graphics Post-Processor.

## **Properties**[¶](#properties "Permanent link")

#### **System**[¶](#system "Permanent link")

Name

Explanation

Type

Unique ID

The unique ID of the runtime post-processing effect to remove.
