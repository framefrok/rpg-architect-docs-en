# Add Graphics Post-Processor

## **Add Graphics Post-Processor**[¶](#add-graphics-post-processor "Permanent link")

Adds a configured graphics post-processing effect to the current scene at runtime, on a chosen layer (the scene, the user interface, or the whole composite frame). Assign the command to a variable to store the new effect's unique ID so it can later be adjusted or removed.

## **Properties**[¶](#properties "Permanent link")

#### **System**[¶](#system "Permanent link")

Name

Explanation

Type

Effect

The post-processing effect to add, including its configured parameters and target layer.

[Graphics Post Processor](../../../05-reference/graphics-post-processor/)

The variable to store the added effect's unique ID in.

[Variable or Value](../../../05-reference/variable-or-value/)
