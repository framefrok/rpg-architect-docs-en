# Graphics Post-Processor

## **Graphics Post-Processor**[¶](#graphics-post-processor "Permanent link")

Graphics post-processor data sources get information about a runtime graphics post-processing effect, referenced by its unique ID.

## **Properties**[¶](#properties "Permanent link")

#### **Properties**[¶](#properties_1 "Permanent link")

Name

Explanation

Type

Layer

The render layer of the post-processing effect (0 = scene, 1 = user interface, 2 = composite).

Number

Token

The token identifying the post-processing effect, such as grayscale.

String

Parameter Value

The value of a named parameter on the effect. Specify the parameter name as the index.

Number
