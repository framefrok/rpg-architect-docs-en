# Video

## **Video**[¶](#video "Permanent link")

RPG Architect supports the following video encoding types for videos:

*   **Theora / Ogg** (.ogm, .ogg)

> **Note**: You can learn about using [VLC](https://www.videolan.org/) to encode [Theora](https://en.wikipedia.org/wiki/Theora) movies via this [guide](https://archive.flossmanuals.net/ogg-theora/encoding/vlc.html).
