# Tags

## **Tags**[¶](#tags "Permanent link")

Tags are key-value pairs that add extensibility to objects. Any object that supports tags ([Entities](../entity/), items, heroes, etc.) can have arbitrary data attached via string keys and string values.

Tags are commonly used with [Filters](../filter/) to power [User Interface Contexts](../../10-user-interfaces/user-interface-context/), allowing interfaces to display data conditionally based on tag values.

Tag values support [Text Escape Codes](../text-escape-codes/).
