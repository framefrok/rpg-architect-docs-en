# Unique ID

## **Unique ID**[¶](#unique-id "Permanent link")

A Unique ID is a globally unique identifier (GUID) assigned to physics-interactive objects in the engine — entities, vehicles, heroes, items, and more.

Unique IDs allow you to save a reference to a specific object in a [Variable](../variable/) and access it later, regardless of where it is in the game world. This is the most flexible way to reference objects and is used by commands like [Save Unique ID](../../07-commands/01-data-manipulation/03-save-unique-id/) and the "By Unique ID" option in [Actor References](../actor-reference/) and [Physics Object References](../physics-object-reference/).
