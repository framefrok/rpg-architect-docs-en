# Script

## **Script**[¶](#script "Permanent link")

Scripts are programmable elements that contain [Commands](../../07-commands/) to execute. They can be authored visually in the editor or as text-based code.

Scripts appear in many contexts: [Entities](../entity/) use them for behavior and interaction, [Global Scripts](../../06-database/10-system/80-global-scripts/) run shared logic, [User Interfaces](../../06-database/09-user-interfaces/00-user-interfaces/) use them for event handling, and battle events trigger them during combat.

When attached to an [Entity](../entity/), scripts gain additional capabilities: [Conditions](../condition/) that must be met, and [Interactions](../interaction/) that trigger execution (such as action button presses, touch events, or auto-run).
