# Font

## **Font**[¶](#font "Permanent link")

RPG Architect supports the following font formats:

*   **OTF** (.otf) — OpenType Font
*   **TTF** (.ttf) — TrueType Font

Fonts are configured through [Font Families](../../06-database/09-user-interfaces/01-font-families/) in the database, where you assign font files and set default sizes, styles, and colors.
