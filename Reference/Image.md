# Image

## **Image**[¶](#image "Permanent link")

RPG Architect supports the following image formats:

*   **bmp**
*   **jpeg**
*   **png**

Images up to 16,386 x 16,386 are supported, but not well. It is strongly recommended to try to keep your images under these dimensions (real world testing shows 8,192 x 8,192 to be fairly stable).
