# Switch or Value

## **Switch or Value**[¶](#switch-or-value "Permanent link")

A flexible boolean construct that resolves to either a constant true/false value or the runtime value of a [Switch](../switch/). Allows commands and settings to be driven by dynamic switch state or fixed values.
