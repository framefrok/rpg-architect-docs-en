# Variable or Value

## **Variable or Value**[¶](#variable-or-value "Permanent link")

RPG Architect supports a powerful construct in the form of allowing many commands and settings to run on either variable or values.

**Value** and **Global** will always be available for variable or value options. In the event that the situation allows for a **Local** variable, this option will also be enabled.

Each usage will be different, as [Variables](../variable/) can support whole numbers, floating-point numbers, strings, and arrays.
