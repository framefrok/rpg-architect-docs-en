# Editor Settings

## **Editor Settings**[¶](#editor-settings "Permanent link")

Editor Settings control how the RPG Architect editor behaves, the defaults applied to new project assets, and the appearance of preview panes. Open the dialog from the **Editor Settings** menu, then select **Edit Settings**. The settings are organized into the categories below.
