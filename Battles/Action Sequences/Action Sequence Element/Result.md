# Result

## **Result**[¶](#result "Permanent link")

Result elements control when and how battle action results are displayed.

> **Note**: If no Target Effect Animation Elements have been specified in an Animation, this will be used for anything remaining. If no Target Effect Animation Element has been provided, no Animation has been provided, and no Result has been provided, nothing will display.
