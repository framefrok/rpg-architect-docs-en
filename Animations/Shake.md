# Shake

## **Shake**[¶](#shake "Permanent link")

Shake elements create a screen or target shake effect.

> **Note**: For example, conveying impact or earthquakes.

## **Properties**[¶](#properties "Permanent link")

#### **System**[¶](#system "Permanent link")

Name

Explanation

Type

Duration

The duration of the shake effect in milliseconds.

Number

Name

The name of this animation element. Used for identification in the timeline.

String

#### **Appearance**[¶](#appearance "Permanent link")

Name

Explanation

Type

Is Screen Effect

Whether to shake the entire screen. When disabled, only the animation target shakes.

Toggle

Name

Explanation

Type

The intensity of the shake in three-dimensional space. Higher values produce more violent shaking.
