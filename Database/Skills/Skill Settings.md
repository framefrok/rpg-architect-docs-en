# Skill Settings

## **Skill Settings**[¶](#skill-settings "Permanent link")

Skill Settings defines how skill usage works across the entire project. It controls the global rules that apply to every skill, such as whether the player is prevented from using a skill or item that would have no meaningful effect on its target.

The settings here are the project-wide defaults that apply to every skill unless an individual skill overrides them. Most projects configure these once early in development to lock in how skill usage feels.

## **Properties**[¶](#properties "Permanent link")

#### **System**[¶](#system "Permanent link")

Name

Explanation

Type

Prevent Pointless Use

When enabled, the player is blocked at the menu from using a skill or item that would have no meaningful effect on its current target.
